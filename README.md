# Komentář k vyhlášce ministerstva spravedlnosti České republiky č. 37/1992 Sb., o jednacím řádu pro okresní a krajské soudy

Otevřený komentář k jednacímu řádu pro okresní a krajské soudy — § po §: doslovné znění, výklad, zmocnění a jeho meze, kazuistika, protiargumenty a praktický závěr; organizace a úkoly soudních osob, nahlížení do spisu, jednání a úkony soudu, doručování, náhrady svědků, trestní agenda, výkon rozhodnutí (movité i nemovité věci, dražby), řízení o pozůstalosti, pověřování notářů a úschovy.

Konsolidované znění: dokument e-Sbírky `SB-1992-00037_2026-01-01`.
